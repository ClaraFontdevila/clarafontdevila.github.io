# clarafontdevila.github.io

Personal website of Clara Fontdevila, built with Quarto and published with GitHub Pages (from the `docs/` folder).

## How to update

- **Bio, teaching, layout:** edit `index.qmd`
- **Publications:** edit `publications.yml` (copy an existing entry and change it; `topics` controls the filter buttons)
- **Look and feel:** `styles.css`
- **Photo / CV / syllabus:** replace `photo.jpg`, `cv.pdf`, `syllabus-actors-education-development.pdf`

Then click **Render** in RStudio (or run `quarto render`), and commit + push. The site updates a minute or two later.
